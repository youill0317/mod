# mod

Claude Code에 붙여 쓰는 개인용 mod 모음입니다.

## shell-memo

메인 Claude가 포그라운드로 셸 명령이나 스크립트를 실행하는 동안, 진행 중 문구 옆에 지금 무엇을 하는지 짧은 메모를 붙입니다. Claude Code가 원래 보여 주는 문구, 시간, 토큰은 그대로 둡니다.

```
✻ Sauteing… · Kaggle 결과 기다리는 중 (7m 45s · ↓ 3.2k tokens · esc to interrupt)
✻ Sauteing… · 테스트 실행 중 · 코드 형식 검사 중 (12s · ↓ 1.1k tokens · esc to interrupt)
```

동작 방식은 다음과 같습니다.

- 명령이 시작되면 Claude가 명령과 함께 보낸 영어 설명을 바로 붙입니다.
- 1~2초 뒤 Haiku가 만든 쉬운 한국어 메모로 바꿉니다. 명령 실행은 이걸 기다리지 않습니다.
- 명령이 둘 이상이면 시작한 순서대로 옆으로 이어 붙이고, 줄이 모자라면 "외 N개"로 줄입니다.
- 명령이 끝나면 메모가 사라집니다.
- 서브 에이전트 창에서는 그 에이전트가 실행하는 명령의 메모를 붙입니다.
- 백그라운드로 실행한 명령과 셸 외 도구에는 붙이지 않습니다.
- 명령을 모델에 보내기 전에 토큰, 비밀번호, 키처럼 보이는 값을 가립니다.

메모를 만드는 모델은 `/config`에서 바꿀 수 있습니다. 기본값은 `haiku`입니다.

### 설치

터미널에서 Claude Code를 열고 다음을 입력합니다.

```
/plugin install shell-memo --marketplace youill0317/mod
```

마켓을 추가할지 물으면 `y`를 누르고, 범위는 user를 고릅니다.

## dashboard

작업 과정을 보여 주는 대시보드입니다. 잠시 자리를 비웠다 돌아왔을 때 맥락을 빠르게 파악하고, 자리에 있을 때도 전체 과정을 놓치지 않게 돕습니다. 결과물과 계획은 아티팩트로, 파일은 직접 열어 보는 것으로 두고 여기에는 넣지 않습니다.

`/dashboard`를 입력하면 대화 옆에 창이 열립니다.

```
 Colab 학습 재개                                  보신 뒤 +4
 지금  l4a에서 epoch 2 체크포인트로 학습 재개 중

 ▸ 나를 기다리는 것
   권한 요청: 셸: Kaggle 데이터셋 만들기  3분째
 ▸ 돌아가는 것
   ● 셸  체크포인트를 Kaggle 데이터셋으로 올리기     42초
   ● 서브 에이전트  general-purpose: GPU 패스 추가    26분
 ▸ 지나온 단계  ★ 자리 비운 사이
   ★ 3분 전    L4 세션 두 개가 서버에서 종료됨
   ★ 1분 전    Drive에서 epoch 2 체크포인트 확인
     40분 전   두 세션에서 학습 시작
 ▸ 확인한 상태
   l4a epoch  3/10  (확인 4분 전)
 ▸ 막힌 것
   없음
 ▸ 다음
   epoch 3 결과 확인
```

동작 방식은 다음과 같습니다.

- 칸 구성은 늘 같습니다. 돌아왔을 때 같은 자리를 보면 됩니다.
- 사용자 요청, 셸 실행과 결과, 서브 에이전트 시작과 끝, 권한 요청, 질문, 파일 수정, Claude의 답이 기록으로 쌓입니다.
- Claude는 작업 단계가 바뀔 때만 짧은 신호를 보냅니다. 이 신호는 권한을 묻지 않습니다.
- 단계 신호, 턴 종료, 권한 요청, 질문, 실패처럼 중요한 순간에는 2초 안에, 창이 열려 있을 때의 일반 기록은 20초 안에 묶어서 작은 모델을 깨웁니다. 작은 모델이 기록을 읽고 대시보드 문장을 다시 씁니다. 기본값은 Haiku이고 `/config`에서 바꿀 수 있습니다.
- 경과 시간, 개수, "보신 뒤" 표시는 모델 없이 mod가 직접 셉니다. "보신 뒤"는 마지막으로 직접 입력한 시점부터 셉니다.
- 정해진 간격으로 바깥 상태를 읽지 않습니다. 학습 epoch 같은 값은 Claude가 마지막으로 확인한 값이고, 그래서 확인 시각을 같이 보여 줍니다.
- 기록을 모델에 보내기 전에 토큰, 비밀번호, 키처럼 보이는 값을 가립니다.

| 입력 | 동작 |
|---|---|
| `/dashboard` | 창 열기 |
| `/dashboard refresh` | 지금 다시 정리 |
| `/dashboard close` | 창 닫기 |

알아 둘 점이 두 가지 있습니다.

- 권한 창에서 승인한 순간은 mod가 알 수 없습니다. 그래서 권한 요청 표시는 그 명령이 끝나거나 사용자가 다음 입력을 할 때 사라집니다.
- 창이 대화 옆에 붙으려면 전체 화면 레이아웃(기본값)이어야 하고 터미널 폭이 110열 이상이어야 합니다. 그보다 좁으면 입력창 위에 열립니다.

```
/plugin install dashboard --marketplace youill0317/mod
```

## 개발

```
claude plugin validate <mod 폴더>
claude plugin test <mod 폴더>
```

설치 없이 한 세션에서만 써 보려면 `claude --plugin-dir ./<mod 폴더>`로 실행합니다.
