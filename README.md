# mod

Claude Code에 붙여 쓰는 개인용 mod 모음입니다.

## dashboard

지금 하는 작업을 두 군데에서 보여 줍니다. 진행 중 문구 옆에는 실행 중인 셸 명령의 짧은 메모가 붙고, `/dashboard`를 입력하면 전체 진행 현황을 그린 창이 열립니다.

### 셸 메모

메인 Claude가 포그라운드로 셸 명령이나 스크립트를 실행하는 동안, 진행 중 문구 옆에 지금 무엇을 하는지 짧은 메모를 붙입니다. Claude Code가 원래 보여 주는 문구, 시간, 토큰은 그대로 둡니다.

```
✻ Sauteing… · Kaggle 결과 기다리는 중 (7m 45s · ↓ 3.2k tokens · esc to interrupt)
✻ Sauteing… · 테스트 실행 중 · 코드 형식 검사 중 (12s · ↓ 1.1k tokens · esc to interrupt)
```

동작 방식은 다음과 같습니다.

- Bash 도구 설명에 규칙을 덧붙여, Claude가 명령의 설명(`description`)을 처음부터 쉬운 한국어 메모로 쓰게 합니다. 명령이 시작되면 그 설명을 바로 붙입니다.
- 설명이 한국어가 아니면, 명령이 1.5초 넘게 돌 때 설정된 모델(기본 Haiku)에 메모를 물어 곧 쉬운 한국어 메모로 바꿉니다. 그 전에 끝나는 짧은 명령은 묻지 않습니다. 명령 실행은 이걸 기다리지 않습니다.
- `-p` 실행이나 SDK처럼 진행 중 문구가 없는 세션에서는 메모를 만들지 않습니다.
- 명령이 둘 이상 동시에 돌면 시작한 순서대로 옆으로 이어 붙이고, 줄이 모자라면 "외 N개"로 줄입니다. Claude Code는 읽기 전용 명령만 동시에 실행하고 파일을 바꾸는 명령은 하나씩 실행하므로, 그때는 메모도 하나씩 뜹니다.
- 명령이 끝나면 메모가 사라집니다.
- 서브 에이전트 창에서는 그 에이전트가 실행하는 명령의 메모를 붙입니다.
- 백그라운드로 실행한 명령과 셸 외 도구에는 붙이지 않습니다.
- 명령을 모델에 보내기 전에 토큰, 비밀번호, 키처럼 보이는 값을 가립니다.

### 대시보드 창

이 세션의 작업 현황을 보여 주는 창입니다. `/dashboard`를 입력하면 창이 열리고, 창 크기에 맞춰 그립니다. 메인 Claude는 작업에만 집중합니다. 대시보드는 메인 대화에 도구도 지시도 더하지 않고, 설정된 모델(기본 Haiku)이 세션을 직접 읽어 혼자 맡습니다.

```
 ● 체크포인트를 Kaggle로 옮기는 중
 ▶ 체크포인트 올리는 중  2분

 ╭─────────╮    ┏━━━━━━━━━━━━━━┓    ╭┄┄┄┄┄┄┄┄╮
 │ ✓ 확인  │ ─▶ ┃ ● 이동       ┃ ─▶ ┆ ○ 재개 ┆
 │ epoch 2 │    ┃ Kaggle 6분째 ┃    ╰┄┄┄┄┄┄┄┄╯
 ╰─────────╯    ┗━━━━━━━━━━━━━━┛

 epoch ███░░░░░░░░░░░░░ 2/10  36분 전
 loss  █▆▄▃▃▂▁ 0.51

 실험        val AUC
 t384_lr1e4  0.871
```

- **위쪽**은 지금 돌아가는 것을 기호와 함께 한 줄씩 보여 줍니다. 오른쪽 숫자는 걸린 시간입니다.

  | 기호 | 뜻 |
  |---|---|
  | ● | 지금 하는 일 |
  | ◆ | 나를 기다림: 권한 요청, 질문, 결정할 것 |
  | ▶ | 실행 중인 셸 |
  | ↻ | 백그라운드 셸 |
  | ◎ | 서브 에이전트와 맡은 역할, 그 아래 `└` 마지막 단계 |

- **아래쪽**은 모델이 이 작업에 맞게 직접 설계합니다. 도식의 종류는 정해 두지 않았습니다. 모델에게는 그리기 재료만 줍니다: 글, 가로/세로 배치, 테두리 상자, 화살표, 진행 막대, 추세선, 표, 구분선, 색. 모델은 이것을 조합해 단계 흐름, 체크리스트, 수치 표, 추세, 비교 등 작업에 맞는 모양을 고르고, 작업이 바뀌면 모양도 바꿉니다. 한글과 이모지 폭 계산과 창에 맞추기는 mod가 합니다. 이모지는 Claude Code가 그리는 대로 2칸으로 셉니다. 창에 다 들어가지 않는 블록은 빠지고, 그 뒤에 오는 블록 중 들어가는 것은 그대로 보입니다.
- 화면은 지금 상태만 보여 줍니다. 끝났거나 거절하거나 취소한 일은 남은 일과 기다림에서 빠지고, 노트에는 "하지 않기로 함"으로만 남습니다. 권한 요청은 허용했는지 거절했는지, 질문은 무엇으로 답했는지까지 기록에 남겨 모델이 끝난 요청을 아직 기다리는 것으로 읽지 않게 합니다. Claude의 턴이 끝나면 위쪽의 대기 표시도 지워집니다.
- 시간("36분 전", "6분째")은 모델이 계산하지 않습니다. 모델이 기록 번호로 표시해 두면 mod가 기록 시각으로 채웁니다.

모델이 읽는 맥락은 다음과 같습니다. 모두 읽기만 하므로 메인에는 영향이 없습니다.

- **대화 원문**: 사용자 요청, Claude의 답, 도구 호출과 결과.
- **서브 에이전트의 대화**: 돌아가는 서브 에이전트가 무엇을 하고 알아냈는지.
- **Claude의 계획**: Claude가 쓰는 할 일 목록(TodoWrite, TaskCreate/TaskUpdate).
- **작업 중 Claude의 말**: "이제 테스트를 고치겠습니다"처럼 단계 사이에 하는 말. 단계가 바뀐 신호로 씁니다.
- **작업 폴더**: `git status`, 바뀐 양, 최근 커밋, 백그라운드 셸 출력의 끝부분(엔진이 경로를 알려 줄 때).
- **모델 자신의 노트**: 모델은 매번 목표, 정한 것, 끝난 일, 남은 일, 지켜볼 값을 노트로 고쳐 씁니다. 다음에는 노트와 그 뒤의 새 대화만 읽습니다. 노트는 프로젝트별로 저장되어, 같은 프로젝트의 다음 세션이 일주일 안이면 참고로 이어받습니다.
- **사용자가 바라는 것**: `/dashboard loss 추세 위주로`처럼 적으면 그것을 가장 먼저 따릅니다.

세션 중간에 처음 창을 열면, 모델이 그때까지의 대화를 한 번 읽어(4만 자까지, 길면 앞과 뒤를 남기고 중간 생략) 노트를 만듭니다. 대화를 압축해 첫 노트를 쓰는 셈이고, 메인 대화는 건드리지 않습니다. 그 뒤로는 위 맥락에서 새로 생긴 것만 읽습니다. 세션의 대화가 실제로 압축되면 그 요약부터 다시 읽습니다.

- 창이 보이는 동안에만 모델을 깨웁니다. 중요한 순간(Claude의 단계 사이 말, 계획 변경, 턴 종료, 권한 요청, 질문, 실패)에는 2초 안에, 일반 기록은 20초 안에 깨웁니다. 창이 닫혀 있으면 기록만 쌓고, 창을 열 때 그동안의 대화로 그립니다.
- 모델은 추론 수준 high로 묻습니다. 한 번 읽는 데 처음엔 20~30초, 그 뒤엔 10초 안팎 걸립니다. 첫 화면이 오기 전에는 "대시보드 모델이 세션을 읽는 중… 12초째"가 뜨고, 호출이 실패하면 "모델 응답을 받지 못함 (시간 초과) · 곧 다시 시도"처럼 이유가 뜹니다. 첫 읽기가 실패하면 다음엔 대화를 절반만 읽어 다시 시도합니다.
- 모델에 보내기 전에 토큰, 비밀번호, 키처럼 보이는 값을 가립니다.

| 입력 | 동작 |
|---|---|
| `/dashboard` | 창 열기 |
| `/dashboard <보고 싶은 것>` | 그것을 중심으로 다시 그리기 |
| `/dashboard reset` | 보고 싶은 것과 노트를 지우고, 대화를 처음부터 다시 읽어 그리기 |
| `/dashboard refresh` | 지금 다시 그리기 |
| `/dashboard close` | 창 닫기 |

알아 둘 점이 세 가지 있습니다.

- 권한 창에서 승인한 순간은 mod가 알 수 없습니다. 그래서 권한 요청 표시는 그 명령이 끝나거나 사용자가 다음 입력을 할 때 사라집니다.
- 창이 대화 옆에 붙으려면 전체 화면 레이아웃(기본값)이어야 하고 터미널 폭이 110열 이상이어야 합니다. 그보다 좁으면 입력창 위에 열립니다.
- 셸 메모는 Bash 도구 설명에 규칙을 덧붙이므로 메인 대화에 조금 들어갑니다. 대시보드 창은 메인에 아무것도 더하지 않습니다.

### 설정

메모를 쓰는 모델과 대시보드를 맡는 모델은 같은 설정 하나를 씁니다. `/config`에서 바꿀 수 있고 기본값은 `haiku`입니다. 계정에서 그 모델을 쓸 수 없으면 세션의 모델로 바꿔 묻고, 요청 한도나 과부하로 실패하면 실패가 이어질수록 더 오래 기다렸다가 다시 묻습니다.

### 설치

터미널에서 Claude Code를 열고 다음을 입력합니다.

```
/plugin install dashboard --marketplace youill0317/mod
```

마켓을 추가할지 물으면 `y`를 누르고, 범위는 user를 고릅니다. 예전에 `shell-memo`를 설치했다면 `/plugin uninstall shell-memo`로 먼저 지웁니다. 메모 기능은 이제 이 mod에 들어 있습니다.

## 개발

```
claude plugin validate <mod 폴더>
claude plugin test <mod 폴더>
```

설치 없이 한 세션에서만 써 보려면 `claude --plugin-dir ./<mod 폴더>`로 실행합니다.
