# mod

Claude Code에 붙여 쓰는 개인용 mod 모음입니다.

## dashboard

지금 하는 작업을 두 군데에서 보여 줍니다. 진행 중 문구 옆에는 실행 중인 셸 명령의 짧은 메모가 붙고, `/dashboard`를 입력하면 전체 진행 현황을 그린 창이 열립니다.

### 셸 메모

메인 Claude가 포그라운드로 셸 명령이나 스크립트를 실행하는 동안, 진행 중 문구 옆에 지금 무엇을 하는지 짧은 메모를 붙입니다. Claude Code가 원래 보여 주는 문구, 시간, 토큰은 그대로 둡니다.

```
✻ Sauteing… · Kaggle 결과 기다리는 중 (7m 45s · ↓ 3.2k tokens · esc to interrupt)
✻ Sauteing… · 테스트 실행 중 · 코드 형식 검사 중 (12s · ↓ 1.1k tokens · esc to interrupt)
```

동작 방식은 다음과 같습니다.

- 명령이 시작되면 Claude가 명령과 함께 보낸 영어 설명을 바로 붙입니다.
- 1~2초 뒤 설정된 모델(기본 Haiku)이 만든 쉬운 한국어 메모로 바꿉니다. 명령 실행은 이걸 기다리지 않습니다.
- 명령이 둘 이상 동시에 돌면 시작한 순서대로 옆으로 이어 붙이고, 줄이 모자라면 "외 N개"로 줄입니다. Claude Code는 읽기 전용 명령만 동시에 실행하고 파일을 바꾸는 명령은 하나씩 실행하므로, 그때는 메모도 하나씩 뜹니다.
- 명령이 끝나면 메모가 사라집니다.
- 서브 에이전트 창에서는 그 에이전트가 실행하는 명령의 메모를 붙입니다.
- 백그라운드로 실행한 명령과 셸 외 도구에는 붙이지 않습니다.
- 명령을 모델에 보내기 전에 토큰, 비밀번호, 키처럼 보이는 값을 가립니다.

### 대시보드 창

이 세션의 작업 현황을 보여 주는 창입니다. `/dashboard`를 입력하면 창이 열리고, 창 크기에 맞춰 그립니다.

```
 ● 노드 도식 구현
 ▶ mod 테스트  2분

 ╭───────────╮     ╭─────────────╮   ╭────────────╮
 │ ✓ 메모    │───▶ │ ✓ 대시보드  │─▶ │ ✓ 신호화   │─▶
 │ main 푸시 │     │ 브랜치 푸시 │   │ Haiku 신호 │
 ╰───────────╯     ╰─────────────╯   ╰────────────╯
      │                  │
      ▼                  ▼
 ╭───────────────╮ ╭─────────────╮
 │ ✗ 검증        │ │ ✗ 테스트    │
 │ ↺ 함수 위치 … │ │ ↺ hook 충돌 │
 ╰───────────────╯ ╰─────────────╯

   ╭───────────╮   ┏━━━━━━━━━━━━┓
 ↳ │ ✓ 전환    │─▶ ┃ ● 노드도식 ┃
   │ 도식과 표 │   ┃ 구현 중    ┃
   ╰───────────╯   ┗━━━━━━━━━━━━┛
        │
        ▼
   ╭────────────╮
   │ ✗ 실측     │
   │ ↺ 문제 4개 │
   ╰────────────╯

 메모      ██████████                                       37분
 대시보드            ███████████████                        53분
 신호화                             █████████████           50분
 전환                                            ████████   29분
 노드도식                                                ██ 6분째
```

- **위쪽**은 지금 돌아가는 것을 기호와 함께 한 줄씩 보여 줍니다. 오른쪽 숫자는 걸린 시간입니다.

  | 기호 | 뜻 |
  |---|---|
  | ● | 지금 하는 일 |
  | ◆ | 나를 기다림: 권한 요청, 질문, Claude가 결정을 물은 것 |
  | ▶ | 실행 중인 셸 |
  | ↻ | 백그라운드 셸 |
  | ◎ | 서브 에이전트와 맡은 역할, 그 아래 `└` 마지막 단계 |

- **아래쪽**은 도식만 씁니다. 작은 모델이 작업에 맞는 것을 중요한 순서대로 고르고, mod가 그립니다.

  | 도식 | 모양 | 쓰는 곳 |
  |---|---|---|
  | 단계 | 단계마다 상자, `─▶`로 연결, 실패·대기·재시도는 아래로 `│ ▼` | 작업의 흐름. 거의 항상 맨 위 |
  | 막대 | `█████░░░ 2/10  36분 전` | epoch, 처리 개수, 점수처럼 끝이 정해진 진행률 |
  | 시간 | 단계마다 한 줄, 한 시간 축 위의 막대 | 어디서 시간이 갔는지 |

  단계 상자는 끝난 단계 `✓` 회색, 지금 단계 `●` 파랑 굵은 테두리, 남은 단계 `○` 점선, 실패 `✗` 빨강, 대기 `◆` 노랑입니다. 고치고 다시 해서 넘어간 실패에는 `↺`가 붙습니다.

- 창에 맞추는 일은 mod가 합니다. 넘치면 뒤쪽 도식부터 빼고, 단계 도식이 길면 잘 끝난 곁가지, 나머지 곁가지, 오래된 끝난 단계 순으로 접습니다. 창 크기가 크게 바뀌면 같은 기록으로 다시 그립니다.
- 시간과 막대 옆의 "몇 분 전"은 모델이 아니라 mod가 기록 시각으로 잽니다. 바깥 상태(학습 epoch 등)는 Claude가 마지막으로 확인한 값입니다.
- 사용자 요청, 셸 실행과 결과, 서브 에이전트, 권한 요청, 질문, 파일 수정, Claude의 답이 기록으로 쌓입니다. Claude는 작업 단계가 바뀔 때만 짧은 신호를 보내고, 이 신호는 권한을 묻지 않습니다.
- 창이 보이는 동안에만 작은 모델을 깨웁니다. 중요한 순간(단계 신호, 턴 종료, 권한 요청, 질문, 실패)에는 2초 안에, 일반 기록은 20초 안에 깨웁니다. 창이 닫혀 있으면 기록만 쌓고, 창을 열 때 그동안의 기록으로 그립니다.
- 기록을 모델에 보내기 전에 토큰, 비밀번호, 키처럼 보이는 값을 가립니다.

| 입력 | 동작 |
|---|---|
| `/dashboard` | 창 열기 |
| `/dashboard refresh` | 지금 다시 그리기 |
| `/dashboard close` | 창 닫기 |

알아 둘 점이 두 가지 있습니다.

- 권한 창에서 승인한 순간은 mod가 알 수 없습니다. 그래서 권한 요청 표시는 그 명령이 끝나거나 사용자가 다음 입력을 할 때 사라집니다.
- 창이 대화 옆에 붙으려면 전체 화면 레이아웃(기본값)이어야 하고 터미널 폭이 110열 이상이어야 합니다. 그보다 좁으면 입력창 위에 열립니다.

### 설정

메모를 쓰는 모델과 대시보드 도식을 고르는 모델은 같은 설정 하나를 씁니다. `/config`에서 바꿀 수 있고 기본값은 `haiku`입니다.

### 설치

터미널에서 Claude Code를 열고 다음을 입력합니다.

```
/plugin install dashboard --marketplace youill0317/mod
```

마켓을 추가할지 물으면 `y`를 누르고, 범위는 user를 고릅니다. 예전에 `shell-memo`를 설치했다면 `/plugin uninstall shell-memo`로 먼저 지웁니다. 메모 기능은 이제 이 mod에 들어 있습니다.

## 개발

```
claude plugin validate <mod 폴더>
claude plugin test <mod 폴더>
```

설치 없이 한 세션에서만 써 보려면 `claude --plugin-dir ./<mod 폴더>`로 실행합니다.
